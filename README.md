# AutoCadent

An autonomous agent project for **Syndicate by Maximor**, the September 5–6, 2026 hackathon hosted by Agent Orchestrator (AO).

## Status

Initial project scaffold. The project scope, selected track, architecture, and implementation are still being defined. No runnable application is included yet.

## Hackathon tracks

The project will select one of the two official tracks:

- **Automated Agent Engineering:** Design, test, evaluate, and improve specialized agents with measurable gains.
- **Autonomous Office of the CFO:** Automate an accounting, finance, or treasury workflow, including exceptions and human review.

## Development

```sh
git clone https://github.com/Anthony-Sin/AutoCadent-SyndicatebyMaximor.git
cd AutoCadent-SyndicatebyMaximor
```

Setup and run instructions will be added with the implementation. The event requires AO throughout development; document AO sessions and build evidence for the final demo.

- [ ] Select a track and describe the problem and target users.

- [ ] Document setup, architecture, tools, workflows, and evaluation.
- [ ] Record measurable results, improvements, or user validation.
- [ ] Add all team members' names.
- [ ] Publish a 3–5 minute demo showing the working project, AO sessions, and the AO dashboard's total session count.
- [ ] Submit on Devpost by **September 6, 2026, at 6:00 PM EDT**.
